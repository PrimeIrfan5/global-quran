Privacy Policy — Global Quran Uploader

Last updated: 3 October 2026

What this tool is

Global Quran Uploader is a private tool run by Global Quran. It uploads videos that we make to YouTube and Instagram channels that we own. Only our own accounts sign in to it.

What data it uses

  • It uses the YouTube Data API and the Instagram API only to upload our videos, set their titles and descriptions, add them to our playlists, and read view counts for our own videos.
  • Sign-in keys are stored only on our own computer. They are never shared or sold.

What data it does NOT collect

  • It does not collect, store or share any data about viewers or any other person.
  • It does not use cookies or tracking on this website.

Google user data

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Anyone can remove this tool's access at any time at myaccount.google.com/permissions. YouTube's own privacy rules are in the Google Privacy Policy.
